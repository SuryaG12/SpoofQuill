# Security Policy

## Supported versions

SpoofQuill is a small project. Security fixes are applied to the latest commit on `main`.

## Reporting a vulnerability

Please do not report security issues in a public issue or pull request.

Use GitHub's private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Describe the issue, the steps to reproduce it, and the impact.

If private reporting is unavailable, contact the maintainer through the GitHub profile at https://github.com/SuryaG12 and ask for a private channel before sharing details.

## What to include

- The affected URL, endpoint, or file.
- The steps to reproduce the issue.
- The version or commit you tested.
- Any proof of concept, with secrets and personal data removed.

## Scope

This project analyzes email text. It does not send email, store messages, or keep accounts. Do not test against addresses or systems you do not own. Do not include real private email content in a report.

## Response

Reports are reviewed as time allows. Confirmed issues are fixed on `main` and noted in the commit message. Credit is given on request.
